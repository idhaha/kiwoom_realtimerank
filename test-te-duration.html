    tradingeconomics('japan/government-bond-yield', '3년')
  3. 전체 데이터 (필터 없음): 
    tradingeconomics('japan/government-bond-yield')

  3. 차트가 로드되는지 확인
  4. 브라우저 콘솔에서 필터링 로그 확인:
    • [MultiSeries] TE Function format detected
    • [MultiSeries] TE filtering to X years
