# Quickstart: 메모 탭 검증

1. 메모 탭에서 텍스트 입력 후 [저장] 클릭 → 3초 이내 저장 완료 표시 확인 (SC-001).
2. [Today] 버튼 클릭 → 현재 일시가 굵게 삽입되는지 확인.
3. 네트워크를 끊고 메모 작성 → 새로고침 없이도 `localStorage`에 내용이 남아있는지 개발자도구로 확인 (SC-002).
4. Google Cloud OAuth 앱이 `Testing` 상태라면 동기화 확인 계정이 Google Auth Platform의 테스트 사용자 목록에도 있는지 먼저 확인한다. 서비스 프로필 허용 목록 등록만으로는 Google 권한 승인이 되지 않는다.
5. 테스트 사용자 승인 계정으로 앱 로그인 → 같은 계정의 Google Calendar 접근 권한 요청이 이어지는지 확인한다. 최초에는 Google 권한 동의가 필요할 수 있고, 승인 후 개인 일정과 대한민국 공휴일이 자동 로드되어야 한다.
6. 자동 권한 요청을 닫거나 거부한 경우에도 앱의 다른 기능을 사용할 수 있는지 확인하고, 일정 탭의 [동기화] 버튼으로 권한 요청을 재시도한다.
7. 테스트 사용자에 등록되지 않은 계정은 Google의 `403 access_denied`를 받는 것이 현재 설정에서 예상된 결과인지 확인한다. 서비스 허용 목록은 그대로 두되, 별도 지시가 없는 한 계정을 Google Cloud 테스트 사용자에 추가하지 않는다.
8. 빈 날짜 클릭 → 일정 등록 → 캘린더에 즉시 반영되는지 확인.
9. 공휴일 일정 클릭 → 수정/삭제 버튼이 없는(읽기 전용) 것을 확인.
10. 다른 브라우저에서 메모 저장 후, 원래 브라우저에서 [새로고침] 클릭 → 5초 이내 반영 확인 (SC-003).
