# Quickstart: 메모 탭 검증

1. 메모 탭에서 텍스트 입력 후 [저장] 클릭 → 3초 이내 저장 완료 표시 확인 (SC-001).
2. [Today] 버튼 클릭 → 현재 일시가 굵게 삽입되는지 확인.
3. 네트워크를 끊고 메모 작성 → 새로고침 없이도 `localStorage`에 내용이 남아있는지 개발자도구로 확인 (SC-002).
4. [동기화] 클릭 → Google 로그인 팝업 및 이벤트 로드 확인.
5. 빈 날짜 클릭 → 일정 등록 → 캘린더에 즉시 반영되는지 확인.
6. 공휴일 일정 클릭 → 수정/삭제 버튼이 없는(읽기 전용) 것을 확인.
7. 다른 브라우저에서 메모 저장 후, 원래 브라우저에서 [새로고침] 클릭 → 5초 이내 반영 확인 (SC-003).
