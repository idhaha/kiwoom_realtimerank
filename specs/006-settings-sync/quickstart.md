# Quickstart: 설정 저장·동기화 검증

1. 탭 이름을 변경 → 페이지 새로고침 → 변경된 이름이 유지되는지 확인 (SC-001).
2. 서버를 잠시 중지한 상태에서 설정 변경 → 로컬에는 반영되고 경고가 표시되는지 확인.
3. 서버를 재시작하고 다른 브라우저에서 접속 → 마지막 저장된 서버 설정이 적용되는지 확인 (SC-002).
4. 사용자 정의 탭이 있는 상태에서 "전체 설정을 프로젝트 폴더에 백업하기" → TXT와 JSON 파일이 localhost 서버 프로젝트 루트에 생성되는지 확인.
5. "프로젝트 폴더 백업에서 복원하기" → 가장 최근 JSON 백업을 선택하고 확인 대화상자를 통과한 뒤 탭 구성이 동일하게 복원되는지 확인 (SC-004).
6. 프로젝트 폴더 백업 복원에서 TXT 파일을 선택 → 고정 탭/메모/간격은 복원되지 않고 커스텀 탭만 반영되는지 확인.
7. 상단 백업/복원 버튼에 마우스를 올려 TXT는 사용자 정의 탭만, JSON은 전체 설정을 다룬다는 풍선 도움말이 표시되는지 확인.
