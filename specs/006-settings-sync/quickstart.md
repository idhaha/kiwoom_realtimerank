# Quickstart: 설정 저장·동기화 검증

1. 탭 이름을 변경 → 페이지 새로고침 → 변경된 이름이 유지되는지 확인 (SC-001).
2. 서버를 잠시 중지한 상태에서 설정 변경 → 로컬에는 반영되고 경고가 표시되는지 확인.
3. 서버를 재시작하고 다른 브라우저에서 접속 → 마지막 저장된 서버 설정이 적용되는지 확인 (SC-002).
4. 사용자 정의 탭이 있는 상태에서 "전체 설정 PC에 저장하기" → TXT와 JSON 파일이 순서대로 다운로드되는지 확인.
5. 다운로드한 JSON 파일로 복원 → 확인 대화상자 통과 후 탭 구성이 동일하게 복원되는지 확인 (SC-004).
6. TXT 파일만으로 가져오기 시도 → 고정 탭/메모/간격은 복원되지 않고 커스텀 탭만 반영되는지 확인.
