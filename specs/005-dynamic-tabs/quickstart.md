# Quickstart: 동적 탭 검증

1. `+` → `Dynamic 차트` 선택 → 4개 셀에 기본 심볼이 채워진 탭이 1초 이내 활성화되는지 확인 (SC-001).
2. 셀 심볼을 변경하고 [이동] → TradingView 임베드가 갱신되는지 확인.
3. Investing.com 아이콘 클릭 → 해당 셀이 대체 공급자로 전환되는지 확인.
4. `+` → `Static 차트` 선택 → `[종목입력]` 모달에 커스텀 문법 입력 후 저장 → 구획별 차트가 렌더링되는지 확인 (SC-002).
5. 존재하지 않는 URL을 문법에 포함해 저장 → 다른 항목은 정상 표시되고 해당 항목만 실패하는지 확인 (SC-003).
6. 탭 더블클릭으로 이름 변경, 드래그로 순서 변경, 우클릭 삭제가 모두 동작하는지 확인.
