# Quickstart: 동적 탭 검증

1. `+` → `Dynamic 차트` 선택 → 4개 셀에 기본 심볼이 채워진 탭이 1초 이내 활성화되는지 확인 (SC-001).
2. 셀 심볼을 변경하고 [이동] → TradingView 임베드가 갱신되는지 확인.
3. Investing.com 아이콘 클릭 → 해당 셀이 대체 공급자로 전환되는지 확인.
4. `+` → `금리/환율 차트` 선택 → 새 커스텀 탭이 활성화되고 `[종목입력]` 설정을 열 수 있는지 확인.
5. `+` → `Static 차트` 선택 → `[종목입력]` 모달에 커스텀 문법 입력 후 저장 → 구획별 차트가 렌더링되는지 확인 (SC-002).
6. 존재하지 않는 URL을 문법에 포함해 저장 → 다른 항목은 정상 표시되고 해당 항목만 실패하는지 확인 (SC-003).
7. 탭 더블클릭으로 이름 변경, 드래그로 순서 변경, 우클릭 삭제가 모두 동작하는지 확인.

8. 금리/환율 탭 `[종목입력]`에 `("fred(DGS10)", "미국채 10년물")`을 저장해 FRED 최근 1년 시계열이 표시되는지 확인한다.
9. 입력을 `("fred(DGS10,10y)", "미국채 10년물")`로 바꿔 최근 10년 범위인지 확인한다.
10. 한 행에 `("fred('DGS10','10년')", "미국채 10년물", "fred('DGS2','10년')", "미국채 2년물")`을 입력해 한 차트에 두 선이 표시되는지 확인한다. 세 번째·네 번째 `표현식, 레이블` 쌍도 같은 행에 추가할 수 있다.
11. 새 FRED 시리즈를 추가해 최초 조회가 전체 지정 기간을 채우고, 서버 재시작 뒤 캐시를 재사용하는지 확인한다.
12. 같은 달 두 번째 조회가 마지막 관측일 기준 30일 겹침 구간만 조회하는지 확인한다. 다음 달 첫 조회는 전체 지정 기간을 다시 받아 수정된 과거값을 반영해야 한다.
13. 시리즈를 입력에서 제거해도 디스크 캐시가 유지되고, 다시 등록하면 캐시를 재사용하는지 확인한다. 마지막 사용 시각이 365일 지난 시리즈의 모든 기간 캐시만 서버 시작 또는 하루 주기 정리 때 제거되며, 이후 재조회는 전체 기간부터 다시 채우는지 확인한다.
