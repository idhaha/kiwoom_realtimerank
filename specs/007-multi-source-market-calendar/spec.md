# Feature Specification: 증시캘린더 다중 소스 탭

**Feature Branch**: `007-multi-source-market-calendar`

**Created**: 2026-10-03

**Status**: Implemented

**Input**: 증시캘린더 안에서 토스증권, SEIBro, Investing.com 캘린더를 전환해 확인한다.

## User Scenarios & Testing

### User Story 1 - 캘린더 공급자 전환 (Priority: P1)

사용자는 증시캘린더 고정 탭 내의 `지표/실적 일정`, `배당 일정`, `FED 금리 일정` 작은 탭을 선택해 각 캘린더를 조회한다.

**Independent Test**: 각 작은 탭을 선택했을 때 해당 URL이 iframe에 지정되고 선택 상태가 한 번에 하나만 표시되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 증시캘린더 탭을 처음 연 상태, **When** 화면이 초기화되면, **Then** 토스의 `지표/실적 일정`이 기본 선택으로 표시된다.
2. **Given** 증시캘린더가 열린 상태, **When** `배당 일정` 또는 `FED 금리 일정` 작은 탭을 선택하면, **Then** 해당 캘린더가 iframe에서 로드되고 활성 탭 및 원본 사이트 링크가 갱신된다.
3. **Given** 사용자가 공급자를 전환하고 설정이 저장된 상태, **When** 화면을 다시 초기화하면, **Then** 마지막으로 선택한 공급자가 유지된다.
4. **Given** 외부 사이트가 iframe 임베드를 차단한 상태, **When** 캘린더가 표시되지 않으면, **Then** 사용자는 원본 사이트 링크로 해당 캘린더를 열 수 있다.

### Edge Cases

- 외부 사이트의 CSP/X-Frame-Options 또는 로그인·쿠키 정책은 브라우저가 차단할 수 있으며, cross-origin iframe의 차단 여부를 부모 앱이 완전하게 판별할 수 없다. 원본 사이트 링크를 제공한다.
- 원격 공급자 장애는 다른 공급자 탭 사용이나 토스 프록시에 영향을 주지 않는다.
- 저장된 공급자 ID가 알려지지 않은 값이면 토스를 기본 선택한다.

## Requirements

- **FR-001**: 증시캘린더 안에서 `지표/실적 일정`(토스), `배당 일정`(SEIBro), `FED 금리 일정`(Investing.com) 세 개의 소형 탭을 제공해야 한다.
- **FR-002**: 초기 선택은 기존 호환성을 위해 토스이며, 한 번에 하나의 공급자 iframe만 로드해야 한다.
- **FR-003**: 공급자 선택 시 해당 URL, 탭 선택 표시, iframe 제목, 원본 사이트 링크를 함께 갱신해야 한다.
- **FR-004**: 공급자 선택 상태는 기존 설정 저장/복원 흐름을 통해 유지되어야 한다.
- **FR-005**: Toss는 기존 같은 출처 `/calendar` 프록시를 유지하고, 새 공급자는 명시된 HTTPS URL을 직접 사용해야 한다.
- **FR-006**: 원격 임베드가 차단되더라도 선택된 공급자의 새 창 링크를 제공해야 한다.
- **FR-007**: 키보드 접근성을 위해 탭 역할과 선택 상태를 노출하고 focus-visible 스타일을 제공해야 한다.

## Success Criteria

- **SC-001**: 세 공급자를 각각 선택하면 올바른 iframe URL 및 원본 링크가 설정된다.
- **SC-002**: 공급자 변경 후 재초기화하면 선택한 공급자가 유지된다.
- **SC-003**: 기본 선택에서 기존 Toss 캘린더 동작과 새로고침이 유지된다.

## Assumptions

- 사용자가 제공한 HTML 확인 결과를 근거로 두 URL을 iframe 대상으로 연결하지만, 최종 임베드 허용은 각 사이트의 응답 정책과 브라우저에서 결정된다.
- 세 캘린더를 나란히 배치하는 대신 탭으로 전환하면 기존 캘린더 화면 공간을 유지하면서 동시 원격 로딩을 피할 수 있다.
