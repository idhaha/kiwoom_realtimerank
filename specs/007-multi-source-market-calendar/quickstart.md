# Quickstart: 증시캘린더 다중 소스 검증

1. 앱에서 증시캘린더를 연다. 기본 `지표/실적 일정` 탭에서 기존 Toss 캘린더가 표시되는지 확인한다.
2. `배당 일정` 탭을 눌러 SEIBro iframe이 열리는지 확인한다. 차단되거나 비어 있으면 `원본 사이트 ↗` 링크를 확인한다.
3. `FED 금리 일정` 탭을 눌러 해당 정책·브라우저에서 iframe이 열리는지 확인한다. 필요 시 원본 사이트 링크로 연다.
4. 세 탭을 전환하면서 활성 표시가 하나에만 있고 원본 링크가 선택한 공급자에 맞는지 확인한다.
5. 새로고침 버튼이 현재 선택된 iframe을 다시 불러오는지 확인한다.
6. 공급자를 선택한 뒤 페이지를 다시 열어 선택이 유지되는지 확인한다. 처음 선택 상태인 기존 사용자는 토스가 기본값이어야 한다.
