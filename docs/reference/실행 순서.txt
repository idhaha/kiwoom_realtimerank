만일 포트가 사용중이라고 나오면, 해당 포트가 사용중인 PID를 찾아서 Kill해줌
netstat -ano | findstr :3001

3. git 반영

만일 새로운 폴더나 파일을 커밋하고 github에 올리려면

5. 서버에 코드 적용후 재시작
